# Dharmdev Tourism and Travels — Billing System

Full-stack GST estimate/invoice generator for Dharmdev Tourism and Travels.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Spring Boot (Java 21)
- Database: PostgreSQL

## Structure
- `/backend` — Spring Boot API
- `/frontend` — React app
- `SPEC.md` — full functional spec (data model, GST calculation logic, API, UI requirements)
